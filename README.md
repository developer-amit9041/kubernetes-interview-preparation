# Kubernetes Interview Preparation

Topic-wise Kubernetes interview preparation for developers, with practical focus on Docker, MERN stack, troubleshooting, and AWS/EKS.

## Study Approach

Study one topic at a time. Practise commands and YAML manifests in a local test cluster such as Minikube or kind. Prepare answers using an English interview definition, a clear Hinglish explanation, and a practical command or YAML example.

## Safety Note

Use a test cluster for destructive commands. Never commit passwords, tokens, production credentials, real kubeconfig files, or `.env` secrets.
